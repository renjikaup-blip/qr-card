# 🎁 QR Gift Card Generator

A cute, printable QR code card generator to share links in a special way! Perfect for sharing games, websites, or any URL with a personalized touch.

## ✨ Features

- **Live Preview** - See your card design as you customize it
- **QR Code Generation** - Creates scannable QR codes for any URL
- **Mobile Optimized** - Fully responsive design works great on phones and tablets
- **Print Ready** - Clean print styles for physical cards
- **Download QR** - Save the QR code as an image
- **Copy URL** - Quick copy-to-clipboard functionality
- **Customizable** - Change title, recipient name, instructions, and emoji
- **Real-time Updates** - Preview updates instantly as you type

## 🚀 How to Use

1. Open `qr-card.html` in your browser
2. Enter your URL in the "URL or Link" field
3. Customize the card text and emoji
4. Click **Print / Save as PDF** to print or save
5. You can also:
   - **Download QR** - Save just the QR code image
   - **Copy URL** - Copy the link to clipboard
   - **Click the QR** - Download the QR code directly

## 🎨 Customization

All text fields support emojis! Change:
- **Recipient Name** - Who the card is for
- **Card Title** - Main headline
- **Instructions** - What to do (e.g., "Scan with your phone")
- **Card Emoji** - The stamp/icon on the card

- Uses Google Fonts (Fredoka, Caveat, Plus Jakarta Sans)
